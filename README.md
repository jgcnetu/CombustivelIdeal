Combustível Ideal 🚗⛽

Aplicativo Android nativo desenvolvido em Kotlin para comparação de custos entre etanol e gasolina.

// 📱 Tecnologias
- Kotlin
- Jetpack Compose
- Material Design 3
- Clean Architecture
- MVVM / MVI
- Room Database
- Coroutines & Flow

// 🧠 Arquitetura
O projeto segue os princípios da Clean Architecture, separando responsabilidades em:
- Presentation
- Domain
- Data

// ✨ Funcionalidades
- Comparação de custos entre combustíveis
- Cache local para uso offline
- Validação de inputs
- UI responsiva e moderna
- Feedback visual dinâmico

// 🧪 Testes
- Testes unitários
- Testes de integração

// 🚀 Status
Em publicação na Google Play Store
